Coda is a team of agents that works from Slack. A leader with no code tools of its own hands each request to a specialist - Explorer, Planner, Triager, Researcher or Coder. Only the Coder can change code, and it works on its own git branch and never merges.

**What I built**
- Read-only git for the Explorer, so investigating code can never change it.
- A shared learning store for the whole team, so a repo's conventions learned in one thread help every specialist.
- Slack identity resolution and the leader's Slack tools, fixed through end-to-end Slack scenarios.
- Each specialist exposed as its own AgentOS agent.
- Prototyped approval gates before the Coder runs shell commands or pushes.

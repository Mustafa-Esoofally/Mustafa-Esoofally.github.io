**The project**

An agent platform for a beverage-industry company: a finance agent that answers questions over the company's data, a supplier-profile workflow that researches and profiles suppliers, and browser agents that handle the government websites compliance depends on.

**My part**
- Moved the platform onto Agno 2.0 and AgentOS.
- Added browser-use toolkits so agents can work on old, unreliable government websites on their own - log in, find the right records, download the PDFs, read them and summarize what matters.
- Improved the finance agent and the supplier-profile workflow.
- Added MySQL support so it could run on the company's existing database.

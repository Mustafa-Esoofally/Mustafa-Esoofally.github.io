An agent platform for a beverage-industry company: a finance agent that answers questions over the company's data, and a supplier-profile workflow that researches and profiles suppliers.

**My part**
- Moved the platform onto Agno 2.0 and AgentOS.
- Improved the finance agent and the supplier-profile workflow.
- Added MySQL support so it could run on the company's existing database.

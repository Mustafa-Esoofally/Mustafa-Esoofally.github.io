A learning machine is a set of stores an agent writes to while it works - user profile, user memory, session context, entity memory, learned knowledge and a decision log - and reads from next time. Pal is built on it.

- Built the learning-machine primitives, including full support for teams: learning context, async learning tools and automatic history.
- Kept system prompts and tool scaffolding out of what gets learned, so memories are about the user, not the plumbing.
- Added per-run limits on memory updates across every learning store.
- Kept user identity intact through memory updates, deletes and topic queries.

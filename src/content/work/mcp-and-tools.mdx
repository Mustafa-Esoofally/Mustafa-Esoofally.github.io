- **MCP results in Claude Code:** found and fixed why Claude Code showed no answer from AgentOS MCP tools (structured results without a text body), plus automatic exposure of whole toolkits as MCP tools. The fix shipped in Agno.
- **Docs agents can read:** built llms.txt support - an agent reads a documentation index and fetches only the pages it needs, or loads the docs into a knowledge base. This is how an internal docs agent stays accurate for coding agents.
- **Schemas that survive:** fixed nested tool schemas so MCP tools with complex inputs work with Claude.
- **Keyless web research over MCP**, and authenticated Exa MCP in the deployment templates.
- Toolkits for GitHub, Parallel's Task and Monitor APIs, Daytona, Serper, Crawl4AI and more, plus consistent tool naming across dozens of toolkits.

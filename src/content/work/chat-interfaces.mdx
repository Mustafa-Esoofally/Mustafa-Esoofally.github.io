- **Telegram:** built the interface from scratch - media in and out, live-updating streamed replies with tool and reasoning status, and a Telegram toolkit.
- **WhatsApp:** rebuilt it with media I/O, webhook signature validation, encrypted identities and support for teams and workflows.
- **Slack:** rewrote streaming so replies appear immediately, added file handling, workspace search, channel summaries, agent-to-agent messaging and channel-scoped sessions.
- **The details that make it usable:** fixed Slack's blank reply bubble while streaming, kept approval cards within Slack's limits so a paused agent always shows a button, and added typing and status indicators in Telegram.
